# Build Map

This repo is a standalone Node 20 ESM app for the free NK AI Market Brief MVP.

## Components

- Context: `NK_NEWSLETTER_MVP_CONTEXT.txt` controls scope, source categories, output rules, and safety constraints.
- Source registry: `config/source-registry.json` (registry v2, loaded by `src/source-registry.mjs`) is the canonical registry read at runtime; it holds 12 enabled sources (nine original Google News RSS queries plus three review-yield market scan queries). The legacy `newsletter-sources.json` remains on disk as a deprecated reference until SRC-002 reconciliation and is no longer read by the pipeline.
- Model registry: `config/model-registry.json` (loaded and integrity-locked by `src/model-registry.mjs`) is the canonical REC-MODEL role→model binding. Every reasoning role binds `claude-opus-4-8` as primary, with `claude-sonnet-5` then `claude-haiku-4-5` as fallbacks only. The policy is recorded into each run's telemetry log and public `site/run.json` receipt.
- Stack profile: `config/norma-stack-profile.json` (loaded by `src/stack-profile.mjs`) is the sanitized read-only REC-REPO-SNAPSHOT of MaisonMeta/NormaKamali@main (pinned commit). Its capability term groups power the `normaRelevance` scoring signal in `src/filter-score.mjs` and the "NK stack signal" badges on the review page.
- Source rings: registry 2.1.0 carries `source_ring` (core/extended/discovery) per row, per-run item caps enforced at fetch (`caps.max_items_per_run` → `src/fetch-feeds.mjs`), concurrency-pooled fetching, and GATE-SOURCE-SMOKE activation evidence under `config/activation-evidence/`.
- AI lane (key-gated): `src/ai/packets.mjs` (public-only allowlist packets, untrusted-evidence delimiters, JSON-schema output validation), `src/ai/budget.mjs` (deterministic cost preflight, REC-BUDGET, REC-PRIVACY stub blocking private routing), `src/ai/lane.mjs` (readiness gating on ANTHROPIC_API_KEY + NEWSLETTER_AI_LANE_ENABLED, dry-run by default, Batches API submission path). Wired fail-soft into the orchestrator; every run emits `ai.lane.dry_run` evidence and the public receipt carries `aiLane` status `ready_pending_key`.
- Config: `src/config.mjs` loads no-secret defaults, optional send env vars, normal daily lookback windows, the 4 a.m. America/New_York target hour, and a wider review lookback window.
- Source loading: `src/sources.mjs` validates the source registry and ignores disabled sources.
- Google News RSS: `src/google-news.mjs` builds query feed URLs.
- Feed fetching: `src/fetch-feeds.mjs` uses `rss-parser`, built-in `fetch`, per-source timeout/error codes/fingerprints, per-source events, and an aggregate source-health event.
- Observability contract: `src/observability/catalog.mjs`, `telemetry.mjs`, `machine-record.mjs`, `redaction.mjs`, and `reader.mjs` provide compact versioned JSONL, automatic component discovery, recursive redaction, exact-run querying/verification, one terminal event, and digest/byte integrity checks.
- Run health: `src/run-health.mjs` separates pipeline, content, deployment, and live state so an all-source failure cannot masquerade as a valid empty newsletter.
- Public receipt: `src/run-receipt.mjs` creates the recursively sanitized allowlist written to public `site/run.json`; detailed run state remains private in the outbox and `.newsletter-logs`.
- Normalization: `src/normalize.mjs` strips RSS HTML from summaries, extracts the actual RSS outlet when available, and produces stable item metadata.
- Filtering/scoring: `src/filter-score.mjs` enforces AI-plus-market inclusion from story title/summary text, uses word/phrase-boundary term matching, and scores by priority phrases, title/summary matches, source weight, and recency.
- Dedupe: `src/dedupe.mjs` removes tracking-param URL duplicates and near-identical title duplicates.
- Story diversity: `src/story-diversity.mjs` selects the top review stories while limiting repeated topic clusters to two when enough qualifying items exist and preferring source/category diversity for close scores.
- Summaries: `src/summarize.mjs` creates deterministic summary fields from RSS title/summary only, cleans outlet suffixes, and rotates safe business-facing sentence variants so repeated issue copy is limited.
- Automation status: `src/automation-status.mjs` inspects `.github/workflows/newsletter.yml` and records workflow, daily 4 a.m. retry/watchdog schedules, Pages, retained observability evidence, exact-run live proof, artifact, and manual-push status in run output.
- Live freshness: `src/live-freshness.mjs`, `scripts/should-refresh.mjs`, and `scripts/check-live-freshness.mjs` decide whether scheduled retries should rebuild and verify the live Pages `run.json` after deployment.
- Rendering: `src/render-html.mjs` and `src/render-text.mjs` create escaped HTML/text newsletter outputs.
- Review status: `src/review-status.mjs` marks review readiness and limited-yield states from selected item counts.
- Review page: `src/render-review-page.mjs` creates the static `site/index.html` review page with noindex metadata, status badges, review status, selected-signal label, lead story, story grid when available, actual source outlet labels, scan labels, secondary technical diagnostics, source fetch status, automation status, and `newsletter.txt` link.
- Send gate: `src/send-resend.mjs` keeps email off by default, validates comma-separated recipients after config parsing, requires minimum item count, and uses Resend HTTP API only when all gates pass.
- Time guard: `src/time-guard.mjs` targets 4 a.m. America/New_York daily for non-forced auto sends.
- Orchestrator: `src/run-newsletter.mjs` runs the full pipeline inside one correlated telemetry context, writes detailed private outbox state, writes a public allowlisted receipt, and finalizes success/degraded/skipped/failure evidence.
- Scripts: `scripts/*.mjs` expose preview, daily public refresh, send, build, deploy/live checks, and compact `logs:status`, `logs:verify`, and `logs:query` readers. Scheduler and command events persist in `.newsletter-logs/commands.jsonl`.
- Share handoff: `SHARE_WITH_CYRIL.md` documents local preview, Actions artifact fallback, Pages enablement, expected live link, and copy/paste review message.
- Auto refresh and deploy: `.github/workflows/newsletter.yml` runs manual dispatch plus daily redundant schedules at `2,7,12,17,22,27,32,37,42,47,52,57 8,9 * * *` and `17 10,11,12 * * *`, persists the live freshness decision before dependency install, runs `npm ci`, tests, daily public output for `auto` mode, exact-run log verification, deploy checks with mode/lookback/fresh-date/health guards, artifact upload, optional Pages deploy gated by `DEPLOY_GITHUB_PAGES=true`, post-deploy live freshness verification, and a final 30-day observability artifact under `always()`.

## Data Flow

Sources -> Google News RSS URL -> RSS fetch/parse with per-source machine events -> normalized metadata with outlet source -> filter/score -> dedupe -> story-diversity selection in preview mode or top-score selection in daily auto mode -> deterministic story summaries -> four-axis run health + review/automation status -> email HTML/text render plus review-page render -> detailed private outbox + integrity-checked JSONL/manifest/summary + sanitized public receipt/static site -> exact-run log and deploy checks -> retained artifact and optional GitHub Pages -> live freshness event -> optional gated Resend email outside the default public daily workflow.

## Trust Boundaries

- External RSS and public live JSON are untrusted; parsing, normalization, timeouts, safe error fingerprints, output escaping, and health checks run before acceptance.
- Email configuration and provider credentials remain private environment inputs. Secret values, recipients, provider IDs, raw errors, and raw external payloads are excluded or redacted from logs and public receipts.
- `.newsletter-logs/` and the detailed dated outbox are private operational evidence. `site/` is public-capable and receives only the explicit receipt allowlist.
- Workflow/provider state is not inferred from source files: deployment and live status remain `not_verified` until their dedicated checks emit evidence.
